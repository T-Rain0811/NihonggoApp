# NihongoApp

Ứng dụng học tiếng Nhật được xây dựng bằng Python và PyQt6.

## Yêu cầu hệ thống
- Python 3.10 trở lên

## Hướng dẫn cài đặt và chạy trên máy tính khác

1. **Clone repository (tải source code về):**
   ```bash
   git clone <URL_CUA_REPO_GITHB_CUA_BAN>
   cd NihongoApp
   ```

2. **Tạo môi trường ảo (Virtual Environment):**
   Mở terminal / command prompt và chạy lệnh:
   ```bash
   python -m venv .venv
   ```

3. **Kích hoạt môi trường ảo:**
   - Trên **Windows**:
     ```bash
     .venv\Scripts\activate
     ```
   - Trên **macOS/Linux**:
     ```bash
     source .venv/bin/activate
     ```

4. **Cài đặt thư viện cần thiết:**
   ```bash
   pip install -r requirements.txt
   ```

5. **Chạy ứng dụng:**
   Bạn có thể chạy bằng file `run.bat` (trên Windows) hoặc trực tiếp bằng lệnh:
   ```bash
   python run.py
   ```
